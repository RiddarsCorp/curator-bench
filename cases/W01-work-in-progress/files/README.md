# Растворимость малых молекул

Техническое описание проекта: как он устроен и как его запустить.

## Устройство
- `data/raw/` — исходные датасеты, описание столбцов — `data/README.md`.
- `src/config.py` — пути, список признаков, сид.
- `src/data.py` — загрузка и очистка данных.
- `src/splits.py` — разбиения выборки.
- `src/features.py` — производные признаки.
- `src/train.py` — обучение и итоговая оценка.
- `src/evaluate.py` — метрики.
- `notebooks/eda.ipynb` — разведочный анализ.

## Как запустить / воспроизвести
```
pip install -r requirements.txt
python -m src.train
```

Скрипт печатает метрики кросс-валидации Ridge по каркасам на обучающей части.

## Документы проекта
- `RESEARCH.md` — суть исследования: вопрос, ценность, данные, методы.
- `PLAN.md` — план реализации по этапам и шагам.
