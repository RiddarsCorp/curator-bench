# Антибактериальная активность наночастиц

Суть исследования. Устройство и запуск — в `README.md`, план — в `PLAN.md`.

## Научный вопрос
Насколько точно минимальная подавляющая концентрация (log MIC) наночастиц предсказывается по их
физико-химическим свойствам и типу бактерии, и переносится ли модель на данные **другой
лаборатории**.

## Смысл и ценность
Модель позволит отбирать составы наночастиц под конкретный патоген без полного скрининга.
Перенос на чужую лабораторию — главный критерий пригодности: условия измерений различаются.

## Данные
- `Data and Preprocessing/raw/mic_train.csv` — 3200 измерений нашей лаборатории.
- `Data and Preprocessing/raw/mic_external_test.csv` — 480 измерений внешней лаборатории.
  **Внешний тест не используется ни для обучения, ни для подготовки признаков, ни для выбора
  модели** — только для одной итоговой оценки. Он может содержать значения категорий, которых
  нет в обучении (например, покрытия), — это часть проверки переноса.

## Методы
- Категориальные признаки кодируются `OrdinalEncoder`, числовые масштабируются — оба
  обучаются только на `mic_train.csv`; неизвестные категории внешнего теста кодируются как −1.
- Модель — CatBoost; сравнение настроек — кросс-валидация (5 фолдов) на обучающих данных.
- Метрики — RMSE и R² на внешнем тесте; сид 42.
